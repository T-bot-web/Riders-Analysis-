# Bike Riders Analysis Dashboard

## Project Overview
This project focuses on analyzing bike riders performance, revenue, and operational efficiency. The analysis helps identify trends in rides, earnings, rider productivity, and operational issues such as network downtime and missed rides. The project is built as an **end-to-end Data Analytics solution** using Python, SQL, and Power BI.

## Tools & Technologies Used
- **Python (Pandas, NumPy)** – Data cleaning and transformation
- **SQL (SQLite)** – Data storage and querying
- **Power BI** – Data modeling, DAX measures, and interactive dashboard
- **Excel / CSV** – Raw data source
- **GitHub** – Version control and project sharing
